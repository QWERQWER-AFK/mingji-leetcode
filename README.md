# 力扣刷题笔记

记录个人练习题、解题思路、复杂度分析和代码。仓库为公开仓库，提交内容任何人都可以查看。

## 目录约定

每道题单独建目录，题号补足 4 位并使用简短英文 slug：

```text
problems/
  0001-two-sum/
    README.md       # 题目链接、个人摘要、思路与复杂度
    solution.py     # 按语言分别保存代码，如 solution.js、Solution.java
templates/
  problem.md        # 题目记录模板
```

新题可复制 `templates/problem.md` 到对应题目目录，再创建相应语言的代码文件。题目描述请记录自己的简要摘要并链接到力扣原题，不要复制整段题面。
